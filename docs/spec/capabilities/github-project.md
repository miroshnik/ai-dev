# github-project

Скилл `github`, `project check` и `project fix`: проект GitHub репозитория сверяется с каноном `AGENTS.md` по
пунктам ✅/❌ и доводится до него.

Сверка и исправление — одна функция: каждое расхождение несёт свой шаг, поэтому `check` и `fix` не расходятся.
Что умеет API, `fix` делает сам; чего в API нет (workflow, сортировка, колонки доски) — шаг UI со ссылкой;
удаление и переименование в проекте с задачами и настройки организации — только с `--confirm`. Ответы GitHub —
записанные с проекта ai-dev (`tests/lib/github-ai-dev.json`), `gh` подменён: мутации меняют запись так, как это сделал бы GitHub.

## check — сверка с каноном по пунктам

- ✅ проект ai-dev как записан — все пункты ✅, код 0; в личном аккаунте Priority и типы issue не проверяются
- ✅ workflow «Item added to project» и «Auto-add to project» не настраивали — ❌ «не настроен», код 1
- ✅ выключенный «Item closed» — ❌ «выключен», отличается от ненастроенного
- ✅ фильтр, чужой вид, доска не по Status и лишнее представление — ❌ представлений с каждой причиной
- ✅ чужие варианты Status, недостающее числовое поле и своё поле сверх канона — ❌
- ✅ закрытая не в Готово, закрытая без выполнения в проекте, открытая вне проекта и без Status — ❌
- ✅ к репозиторию не привязан проект — единственный пункт ❌, остальное без проекта не проверить
- ✅ облачная сессия — объяснение и код 2, а не сбой gh на Projects v2

## fix — довести до канона

- ✅ исправимое через API исправляет сам и сверяет заново: все ✅, код 0
- ✅ закрытая задача не в Готово — ставит Готово и просит проверить цель «Item closed» в UI
- ✅ ненастроенные workflow — шаги UI со ссылкой на список workflow проекта, API их не включает
- ✅ доска не по Status — шаг UI со ссылкой на представление
- ✅ в проекте с задачами удаление и переименование — только с --confirm, до него списком на подтверждение
- ✅ проекта нет — привязывает одноимённый проект владельца, а не заводит новый
- ✅ проекта нет — копирует эталон под владельца репозитория и привязывает; из шагов остаётся только auto-add
- ✅ эталон недоступен — создаёт проект с нуля: варианты Status переименовывает с теми же id, View 1 → Таблица
