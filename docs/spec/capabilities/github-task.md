# github-task

Скилл `github`, `task new`, `task status` и `task drop`: задача по канону `AGENTS.md` одной командой — тип или
метка, проект и `Бэклог`, `Priority`, эпик, blocked by, milestone; статус с эпиком; закрытие без выполнения.

Всё проверяется до создания: задача не появляется наполовину. Ответы GitHub — записанные с проекта ai-dev
(`tests/lib/github-ai-dev.json`), `gh` подменён: мутации меняют запись так, как это сделал бы GitHub.

## task new — задача одной командой

- ✅ подзадача эпика: заголовок с префиксом эпика, в проекте в Бэклог, sub-issue, blocked by, следующий шаг — оценка
- ✅ заголовок уже с префиксом эпика — префикс не удваивается
- ✅ закрытый блокер пропускается — он уже не блокирует
- ✅ тело задачи — из файла --body-file
- ✅ эпик в личном аккаунте — метка epic вместо типа; эпик не оценивается
- ✅ метки epic в репозитории нет — создаёт её и ставит
- ✅ задача и баг в личном аккаунте — без типа и без меток
- ✅ milestone — по названию среди открытых

### ошибка до создания — задача не заводится наполовину

- ✅ --epic указывает не на эпик
- ✅ эпик закрыт
- ✅ открытого milestone с таким названием нет
- ✅ открытая задача с тем же заголовком уже есть — дубль не заводится
- ✅ в личном аккаунте --priority — приоритет там не ведём
- ✅ блокера нет в репозитории
- ✅ проекта нет — сначала project fix

## task new в организации: тип issue и Priority

- ✅ тип issue организации и Priority Medium по умолчанию — в той же мутации, что и задача
- ✅ подзадача срочнее эпика — Priority эпика поднимается до неё; не срочнее — эпик не трогается
- ✅ выключенный тип или чужое значение Priority — ошибка до создания

## Гонка с элементом проекта

GitHub добавляет задачу в проект не мгновенно для чтения: ответ createIssue и чтение задачи могут ещё не показывать
элемент, а повторное добавление отвечает «Content already exists». Статус всё равно ставится — по элементу, который
станет виден после короткой паузы.

- ✅ createIssue ещё не показывает элемент, добавление — «уже есть»: task new всё равно ставит Бэклог
- ✅ задачу проект уже добавил, а чтение её ещё не показывает: task status перечитывает с паузой и ставит статус
- ✅ элемент так и не виден — понятная ошибка с тем, что повторить, а не падение

## task status — Status в проекте

- ✅ подзадача «В работе» — эпик из Бэклог тоже «В работе»: взята первая подзадача
- ✅ эпик уже в работе — не трогается
- ✅ задача вне проекта — добавляется и получает статус
- ✅ последняя подзадача закрыта и в Готово — подсказка закрыть эпик
- ✅ статус не из канона — ошибка, ничего не меняется

## task drop — закрыть без выполнения

- ✅ закрывает как not planned и убирает из проекта
- ✅ --duplicate-of — закрывает как дубль со ссылкой на оригинал
- ✅ подзадача эпика — подсказка пересчитать оценку эпика
- ✅ уже закрыта без выполнения, но в проекте — только убирает из проекта
- ✅ выполненную задачу не трогает — ошибка
