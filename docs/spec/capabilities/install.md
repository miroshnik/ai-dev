# install

Установка флоу: `npx github:miroshnik/ai-dev install` ставит общие правила, справочники и все скиллы в проект,
с `-g` — на машину.

В проекте всё копией в `.agents/` (коммитится: облачная сессия и CI видят ровно эту версию), Claude Code
получает симлинки из `.claude/`, остальные агенты — ссылку в `AGENTS.md` проекта. На машине — `~/.agents/` и
агенты, которые на ней есть.

## Установка в проект

- ✅ правила, справочники и все скиллы — копией в .agents, Claude Code получает их симлинками из .claude
- ✅ в AGENTS.md проекта — блок со ссылкой на правила: свой текст проекта на месте, повторная установка блок не дублирует
- ✅ без AGENTS.md в проекте — файл создаётся с одним блоком
- ✅ скилл, которого больше нет в ai-dev, при переустановке удаляется; свой скилл проекта не трогается
- ✅ чужой каталог с именем скилла ai-dev не перезаписывается — предупреждение
- ✅ корень установки — корень git-репозитория, даже при запуске из подкаталога

## Установка на машину (-g)

- ✅ правила и скиллы — в ~/.agents; агентам, что есть на машине, — симлинки, отсутствующим каталоги не создаются
- ✅ чужой непустой файл правил агента не трогается — предупреждение
- ✅ старый симлинк install.sh ~/.claude/CLAUDE.md → claude/CLAUDE.md убирается — правила не грузятся дважды
- ✅ свой ~/.claude/CLAUDE.md пользователя остаётся
- ✅ --link из клона — симлинки на клон вместо копий: правка в клоне видна сразу
- ✅ AI_DEV_PRIVATE — ~/.config/ai-dev становится симлинком на личную конфигурацию

## Ошибки

- ✅ --link без -g — код 2: в проект коммитится копия, не ссылка на локальный клон
