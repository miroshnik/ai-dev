# dashboard

Скилл `dashboard`: страница в браузере, где по времени видно, сходятся ли оценки задач с фактами и падает ли цена
задачи, — чтобы править флоу по цифрам, а не по ощущению.

Флоу меняется ради двух величин: точности оценок и стоимости задачи. `est history` показывает их таблицей — отдельные
задачи видны, тренд нет. Дашборд берёт те же данные (поля проекта GitHub и маркеры комментариев «Оценка» и «Факт»,
через скрипт `est` рядом) и рисует их по дате закрытия задачи; в GitHub ничего не пишет.

## Почему один график из четырёх панелей

Часы, токены и доллары — разные единицы. На одной панели с двумя шкалами их взаимное положение произвольно: график
рисует связь, которой в данных нет. Поэтому панели отдельные, ось времени общая, шкала значений у каждой своя — и
логарифмическая: задачи различаются в десятки раз, а точность оценки — отношение, на такой шкале ×2 выше и ×2 ниже
одинаково далеки от оценки.

Четвёртая панель — факт к оценке: на панели часов оценка и факт сотни задач — пары точек, сходятся ли они, по ним
не прочесть. Отношение с линией ×1 и полосой допуска ×0,5…×2 отвечает на этот вопрос прямо, а его тренд — это k
во времени.

Точка — задача, линия — скользящая медиана последних 10 задач: задачи разного размера, среднее тянет одна большая.
Оценка идёт только с маркером `est` — старые оценки в других единицах, как и в k. Эпик в график не входит: его часы
— сумма подзадач, они уже на графике.

## Почему страница рисуется на сервере

SVG собирается строкой в скрипте — геометрию проверяет `bun test`, без браузера, зависимостей и CDN. В браузере
остаётся только подсказка при наведении; всё, что она показывает, есть и в таблице под графиком.

Сервер слушает только `127.0.0.1` и отвечает только на своё имя: страница называет задачи непубличных
репозиториев, а сайт, навёдший своё имя на `127.0.0.1` (DNS rebinding), читал бы её из браузера пользователя.

Отвергнуто: подкоманда `est dashboard` — графиков станет больше, а `est.ts` уже велик; файл HTML без сервера —
данные устаревают в момент записи, а страница с сервером перечитывает проект при открытии.
