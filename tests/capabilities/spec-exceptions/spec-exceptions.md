Исключения решения живут файлом на элемент — `exceptions/<элемент>.json` в папке решения, а не массивом в
`exceptions.ts`: подзадачи разбора долга параллельно убирают каждая своё исключение, и в общем массиве каждая
следующая получала конфликт соседних строк и повторный прогон CI. Удаление своего файла ни с чем не пересекается.

Проекту, где исключения ещё в `exceptions.ts`, переезд — одной командой: `spec-exceptions` раскладывает каждый файл
по каталогу, удаляет старый и меняет импорт в тестах папки на `exceptionsIn()` харнесса; что переписать не смогла —
называет. Харнесс на `exceptions.ts` в папке решения падает тестом с подсказкой этой команды.

Отвергнуто: сортировка массива — соседние удаления всё равно конфликтуют; `merge=union` в `.gitattributes` — при
удалении соседних строк возвращает обе, и снятое исключение молча оживает.
