# ai-dev

Конфигурация Claude Code для всех моих проектов: общие правила и пользовательские скиллы.

Иерархия:

- `claude/CLAUDE.md` — глобальные правила (ведение задач в GitHub Issues + Projects,
  milestones, оценка и факт). В `~/.claude/CLAUDE.md` — симлинк сюда.
- `claude/skills/<name>/` — скилл по [документации Claude Code](https://code.claude.com/docs/en/skills):
  `SKILL.md` (промпт: frontmatter + процедура) и `scripts/` (детерминированная часть).
  Симлинки — в `~/.claude/skills/`.
- `install.sh` — ставит симлинки из `~/.claude` на файлы репозитория.

Всё, что зависит от конкретных репозиториев (какие есть, где лежат, номера проектов),
живёт только локально в `~/.claude` — в репозитории этого нет.

Скиллы:

- `est` — оценка задач по истории проекта (аналоги с фактом, коэффициент k) и факт
  в активных часах Claude Code из транскриптов сессий.

Задачи по этому репозиторию — в Issues и проекте `ai-dev`, по правилам из `claude/CLAUDE.md`.
